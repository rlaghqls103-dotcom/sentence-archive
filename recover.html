감상문 되살리기

컴퓨터 브라우저에 남아 있는 문장 수집창고의 옛 저장본에서 감상문을 찾아요. 파일은 이 화면 안에서만 읽고, 어디에도 보내지 않아요.

1. 브라우저 저장 폴더 복사하기

  1. 문장 수집창고를 쓰던 브라우저(크롬 또는 엣지)를 완전히 꺼요. 설치한 앱 창도 닫아요.
  2. 파일 탐색기(맥은 Finder) 주소창에 아래 경로를 붙여넣고 엔터를 눌러요.
    윈도우

    크롬: %LOCALAPPDATA%\Google\Chrome\User Data\Default\Local Storage\leveldb

    엣지: %LOCALAPPDATA%\Microsoft\Edge\User Data\Default\Local Storage\leveldb

    맥 (Finder → 이동 → 폴더로 이동)

    크롬: ~/Library/Application Support/Google/Chrome/Default/Local Storage/leveldb

    엣지: ~/Library/Application Support/Microsoft Edge/Default/Local Storage/leveldb

    프로필을 여러 개 쓰면 Default 대신 Profile 1 같은 폴더일 수 있어요.

  3. leveldb 폴더를 통째로 바탕화면에 복사해요. 원본은 건드리지 않아요.

2. 복사한 폴더 고르기

이 화면은 다른 브라우저로 열어도 돼요. 아래 버튼을 누르고 바탕화면에 복사한 leveldb 폴더를 고르세요. (폴더를 고를 수 없으면 폴더 안 파일을 모두 선택하세요.)
